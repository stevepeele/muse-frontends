How it works

  • 1Pick an interface. Each one is a single Muse template, given a single job.
  • 2Type one prompt. No system-prompt pasting, no setup, no chat history to manage.
  • 3The template runs. The interface config is the template — it executes on the deployer's API key and streams the result back.

Run your own

This whole thing is a self-deployable product. Fork it, point it at your own templates, put it on your own domain.

  1. Fork the repo and import it into Vercel — or hit the Deploy button.
  2. Set ANTHROPIC_API_KEY in the Vercel project environment. Your key, your bill — runs cost a few cents each.
  3. Add your own interface: copy an interfaces/*.json file, point system_prompt at your side-chat or template definition, redeploy. No code changes.
  4. Point your domain at the deployment. Done.
